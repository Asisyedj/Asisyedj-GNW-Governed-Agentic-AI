## 3. Execution & Verification via API

Every skill in the catalog is exposed via the GNW Governed HTTP API:

- **List Skills**: `GET /api/skills`
- **Filter Skills**: `GET /api/skills?category=research_and_intel&specialist=research`
- **Inspect Metadata**: `GET /api/skills/:skillId`
- **Governed Execution**: `POST /api/skills/:skillId/execute`
